## 🔵Binary Representation🔵 

### ✅ Binary system ✅
It was created to represent numbers using only 1 and 0. It is how computers work behind when we use them.  
We carry over to write numbers in decimal system.

🔴How to read binary system🔴:  
1) On units place write 2^0, on tens 2^1 .....  
2) Then multiply the respective 2^ annotation with the number on that place(1/0).  
3) Add the results, you get your number.

### ✅Negative Quantities✅
Unsigned systems can only show positive numbers while signed systems can shows negative numbers too. However, a signed system will reduce the range for number by half 1 at start in signed system shows negative number. eg: 111 in unsigned systems is 4+2+1 = 7, in signed system it is -4 + 2 + 1 = -1.

1's complement means inverting 0 into 1 and viceversa.  
2's complement means adding 1 to 1's complement.

2's complement is done to deal with negative numbers in the computer system. If you want -78, you find 2's complement of 78, however there are 2 exceptions.
1) you cant apply it to zero since you would need be able to fit into that bit system.
2) in case you have nth bit system then u cant apply to -2^(n-1) since:
   -128 is written as 10000000 --> 01111111 --> 1000000.(we get the same number)
